# 🔐 Intelligent Encrypted File Sharing and Digital Collaboration Management Platform

## Overview

The Intelligent Encrypted File Sharing and Digital Collaboration Management Platform is a secure web application designed to help users upload, manage, and share files safely.

The system provides secure user authentication, file management, file sharing, and role-based access control. It also includes an admin dashboard for managing users.

## Objectives

- Provide secure user registration and login.
- Protect user accounts using password hashing and JWT authentication.
- Allow users to upload and manage files.
- Allow users to share single or multiple files.
- Allow users to view files shared with them.
- Provide role-based access control for users and admins.
- Provide a simple and secure file-sharing platform.

## Technology Stack

# 🔐 Module 1: Authentication & Secure File Management

## Milestone 1: Project Setup, Authentication and File Management

### Objective

The first milestone focuses on developing the basic foundation of the TrustShare platform, including user authentication, database setup, file management, file sharing, and admin access.

## User Authentication

The system provides secure user authentication.

The authentication features include:

- User registration
- User login
- JWT authentication
- Password hashing
- Forgot password
- Reset password

## File Management

The system allows users to upload and manage their files.

The file management features include:

- File upload
- View uploaded files
- Manage files
- File storage
- File information management

## File Sharing

Users can securely share files with other registered users.

The system supports:

- Sharing a single file
- Sharing multiple files
- Selecting a recipient
- Viewing shared files

## Admin Management

The system provides role-based access for administrators.

Admin features include:

- View users
- Change user roles
- Delete users
- Manage user access

## Database

PostgreSQL is used to store:

- User information
- Password information
- User roles
- File information
- File sharing information
